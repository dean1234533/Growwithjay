# Business media sources

The active site uses media downloaded from https://www.growwithjay.co.uk/ and its public service/coaching pages. Original files are stored under `assets/growwithjay/`; `manifest.json` records each source URL and file size.

Integrated media:
- Original Jay Marson logo (header and footer)
- Original homepage training film and its poster
- Jay's original portrait
- Four original progress photos
- Original personal training, sports massage and online coaching photos

Brand: Courage To Grow™, Jay Marson. Accent: #a8323b from the live site.

Business contact details, social and policy destinations were read from the live site. Client outcomes are summaries from the public client success stories page, not invented testimonial quotes.

Previous stock media and the earlier illustration are retained as unused files; the HTML and CSS no longer reference them.
