# Courage To Grow™ / Growwithjay

Live: https://dean1234533.github.io/Growwithjay/

Two distinct pages: the coaching homepage (coach, services, client progress, direct contact and consultation booking) and a dedicated Sports Massage page (treatment information, FAQs and appointment booking). Duplicate About, placeholder Pricing and demo Contact pages have been removed.

Run `python3 -m http.server 8765 --bind 127.0.0.1` for local preview. `mobile-preview.html` is a development helper for interactive phone-size previews.

Original business media lives under `assets/growwithjay/`. The online coaching card uses a professional stock photograph; see `assets/stock/SOURCES.md`. Booking and current prices link to the existing business booking system. Email and phone links are direct; no non-functional enquiry form remains.

GitHub Pages publishes changes pushed to main. The existing growwithjay.co.uk domain has not been migrated.
